# Why `heard-again.yml` was removed

**Removed 2026-10-04.** This directory previously held `heard-again.yml` — a complete,
schema-correct awesome-selfhosted entry, written by an agent, for the owner to copy and submit
under their own name.

The destination repo forbids exactly that. `CONTRIBUTING.md` in
`awesome-selfhosted/awesome-selfhosted-data` instructs AI agents:

> Do not write the text of an entry (`software/*.yml`, `tags/*.yml`, `platforms/*.yml`) that a
> person will then submit as their own.

Keeping a ready-to-paste file here would have invited the breach on the day someone worked the
run sheet. So the file is gone rather than annotated.

Separately, Heard Again is **not eligible** for the list until roughly **2027-02-03** — the
public repo has no tagged release, and the rule measures releases, not commits. Full reasoning,
the verified eligibility table, and the YAML schema reference live one level up in
`../awesome-selfhosted-pr.md`.

Nothing in this directory needs to be submitted. Nothing here is a blocker on the W2 launch.
