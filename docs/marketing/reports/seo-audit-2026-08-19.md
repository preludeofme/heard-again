## 3. Broken Links

**Status: ✅ No 404s. Redirect issues found and fixed.**

Crawled all 14 sitemap URLs plus additional routes:

- **No 404s** anywhere on sitemap URLs.
- **Fixed (critical):** `/faq` → was returning `307 → /login?callbackUrl=/faq`. This route appears in the sitemap, the landing-page footer, and privacy/terms footers. FAQ content actually lives at `/#faq`. Redirected the footer link to `/#faq` and removed `/faq` from the sitemap.
- **Fixed (critical):** `/contact` → was returning `307 → /login?callbackUrl=/contact`. No `/contact` page exists. Repointed all six `href="/contact"` references (LandingPage, LoginPage, CreateAccountPage, terms, privacy, terms-legacy) to `mailto:privacy@heardagain.com` (the public support inbox).
- **Root domain:** `heardagain.com/` → `307 → www.heardagain.com/`. This is correct/expected (canonical is www), but it means any non-www links trigger a hop — now eliminated from our own meta tags.

- **Gap:** ❌ **No post has a `coverImage`.** All 5 articles fall back to the shared `og-image.png`, so every post, the homepage, and the blog listing render the *same* social card. This is the single biggest social-engagement opportunity on the site (see Quick Wins).

## 5. Quick Wins (low-effort, high-impact)

1. **Add per-post `coverImage` OG images** — highest impact. Generate a 1200×630 image for each post (even simple branded cards with the post title) and set `coverImage` in each post's `meta`. Transforms social sharing from generic to clickable. The `og-image-pil` skill can automate this.
2. **Auto-regenerate `lastmod` in the sitemap.** Derive from post `date` fields so it stops showing stale `2026-08-09` values.
3. **Trim homepage `title` length.** Current title is ~90 chars — longer than the ~60-char display limit in search results. Most of the important keywords are in the first 60 chars, so this is minor, but reconsider if title CTR is a priority.
4. **Add a `contact` page or keep the `mailto:` link.** Currently contact points to `privacy@`; a dedicated `/contact` page (or a `support@heardagain.com` alias) would be cleaner and avoids funneling support inquiries into the privacy inbox.
